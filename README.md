I am a **PhD analytical chemist** building open-source software for **mass spectrometry**, **scientific computing**, and **laboratory automation**.

I enjoy turning messy experimental data into reliable, robust tools that helps scientists.

## Current projects

* 🧪 **[MassFlow](https://github.com/janusson/MassFlow)** - Vendor-agnostic tandem-mass spectrometry (MS/MS) data annotation, spectral library management, and molecular networking
* 🤖 **[MSMCP](https://github.com/janusson/MSMCP)** - Model Context Protocol (MCP) server to integrate mass spectrometry (MS) data into AI workflows
* 📈 **[PySharpe](https://github.com/janusson/PySharpe)** - Web application for quantitative portfolio optimization built within a scientific Python ecosystem

My background spans high-resolution mass spectrometry (QTOF, TWIMS, Orbitrap, LC-MS/MS, GC-MS, ICP-MS), data engineering, and analytical method development in both academic and industrial laboratories.

I'm interested in computational mass spectrometry, chemical analytics, and building open-source software that makes complex data easier to understand.
